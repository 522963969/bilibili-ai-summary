B站 AI 视频总结{{VERSION}}

在 B 站视频页读取字幕，用你自己的大模型生成摘要、章节与思维导图。这是一个浏览器扩展，没有安装程序，也没有 EXE。

先说最重要的一件事：它本身不会“思考” 扩展不带 AI 能力，也不经过任何人的服务器。你需要自己准备一个大模型服务的地址和一个 API Key（OpenAI、DeepSeek、月之暗面、硅基流动等都行，也可以是自己或公司搭的），填进去才能真正生成总结。没有 Key 时，面板能打开，但只会提示「未配置」。

安装

1解压到一个不会被删的文件夹

右键这个 zip →「全部解压缩」，解压到比如 D:\bilibili-ai-summary 或「文档」里的一个文件夹。

解压出来的这一层就是扩展本体，能看到 manifest.json、assets、icons 这些。请记住这个位置：以后不能删、不能改名、不能移动，否则扩展会失效。也别解压到「下载」文件夹，那里容易被清理。

2在浏览器里加载这个文件夹

Chrome / Edge 通用

  1. 地址栏输入 chrome://extensions（Edge 用 edge://extensions）
  2. 打开右上角（Edge 在左下角）的开发者模式
  3. 点加载已解压的扩展程序
  4. 选中第 1 步解压出来的那个文件夹（里面直接有 manifest.json 的那一层）
  5. 列表里出现「B站 AI 视频总结」即成功

会看到的提示（都正常）

  1. 顶部出现「请停用开发者模式扩展」的黄色提示条 —— 点 × 关掉即可
  2. 扩展图标默认藏在拼图菜单里，建议点图钉固定到工具栏
  3. 浏览器大版本更新后，扩展可能被自动停用 —— 回扩展页把它重新打开
3填自己的模型服务（这一步不做，等于没用）

点扩展图标 →「打开设置」，或者右键扩展图标 →「选项」。在模型服务这一节填三项：

  • API Base URL：服务地址，要填到 /v1 这一层。例如 https://api.openai.com/v1、https://api.deepseek.com/v1。你的服务商文档里叫「base_url」的就是它。
  • API Key：服务商给你的那串密钥，通常以 sk- 开头。
  • 模型名称：要填服务商文档里给的准确名字，例如 gpt-4o-mini、deepseek-chat。填错会报「模型不存在」。

然后：点「测试连接」 → 看到绿色的成功提示 → 点页面最下方的「保存设置」 → 回到「域名授权」那一行点「授权该域名」，在浏览器弹窗里点「允许」。

最后这一步很多人会漏掉。不授权的话，请求会被浏览器直接拦下，表现为「连不上」。

4去 B 站视频页用

打开任意一个 B 站视频（网址长这样：bilibili.com/video/BV...），右侧信息栏会出现一个「AI 总结视频」的入口 —— 也可能藏在右上角，点一下就在下方展开面板。

面板里点「获取字幕」，有多个字幕来源时选一个，然后点「总结」。长视频会自动分段处理，进度显示在面板里。

总结出来后可以导出 Markdown、幕布大纲、字幕 txt，以及思维导图 SVG / PNG。

遇到问题先看这里

现象原因与处理
加载时提示「清单文件缺失或不可读取」 选错了文件夹。要选直接包含 manifest.json 的那一层，不是它的上一级。
面板能打开，但说没配置模型 第 3 步没做完。三项都填了、点了「保存设置」才算生效；「测试连接」用的是已保存的设置。
点「测试连接」报网络错误 / 一直转圈 九成是没点「授权该域名」。其次是 Base URL 少了 /v1，或者你的服务商不允许浏览器直接调用（部分服务需要开 CORS，自建服务要加允许跨域的响应头）。
字幕显示「未获取」 先在 B 站登录。仍不行说明这个视频本身没有公开字幕 —— 此时可以「导入本地字幕」（SRT / VTT / JSON），或在设置里启用「视觉模型」后改用画面识别。
这个视频的字幕被设为需要解锁 是平台限制（UP 主关闭了字幕、或视频是充电/付费专属），扩展不会绕过。换视频或改用导入字幕。
右侧没有「AI 总结视频」入口 确认是 /video/BV... 这种普通投稿页（番剧页不支持），然后刷新页面。刚装完扩展时，已打开的标签页需要刷新才会生效。
总结到一半报错 多半是模型服务超时或限流。设置里「等待回复的最长时间」可以调大，长视频也可以把「每段内容量」调小。
浏览器更新后扩展不见了 / 不工作 未上架商店的扩展在浏览器大版本更新后可能被停用。回扩展管理页重新启用；如果被移除，重新「加载已解压的扩展程序」即可，设置不会丢。

隐私

  • API Key 只存在你本机浏览器的扩展存储里，只发给上面填的那个服务地址，不经过任何第三方中转。
  • 不收集浏览历史、Cookie、剪贴板；没有统计、没有广告、没有远程代码。
  • 字幕只在你点「总结」时发给你自己的模型服务；不点就不发。
  • 总结结果缓存在本机，按视频分开存，不会上传。
  • 本机存储不等同于系统级密钥库，共用电脑上建议用一把限额度的 Key，用完删掉。

不用了怎么删掉

  1. 扩展管理页里点「移除」
  2. 把第 1 步解压出来的文件夹删掉
  3. 如果填过 Key，建议去服务商后台把这把 Key 作废
